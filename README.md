# Kuruva Thulaja Bhavani - Personal Portfolio & Dashboard

A modern, highly interactive personal portfolio dashboard for **Kuruva Thulaja Bhavani**, Final-Year B.Tech Data Science & Engineering student at St. John's College of Engineering and Technology.

---

## 🌟 Key Features

1. **Dashboard-Style Experience**:
   - Desktop left sidebar with profile photo, quick actions, active section indicator, and contact shortcuts.
   - Mobile-responsive navigation bar with backdrop blur and smooth drawer transitions.
2. **Hero Dashboard**:
   - Animated statistics counters: B.Tech Final Year, 82.5% Aggregate Score, 2 Mini Projects, 6 Certifications.
   - Profile avatar with live status indicator ("Available for roles").
   - Quick action buttons ("View Projects", "Contact Me", "Download Resume").
3. **About & Interests**:
   - Career objective aligned with data science, machine learning, and business intelligence.
   - Resume-backed focus areas: Data Science, Machine Learning, Artificial Intelligence, Power BI, Web Development.
4. **Interactive Education Timeline**:
   - St. John’s College of Engineering and Technology (82.5%, Final Year / Pursuing)
   - Akshara Sri Junior College (65%, Intermediate – MPC)
   - National English Medium High School (591/600, SSC)
   - Expandable coursework breakdown and milestone badges.
5. **Categorized Skills Dashboard**:
   - Category filtering: Frontend Technologies, Backend Technologies, Database, Core Domains.
   - Interactive chips, icons, and descriptions (no invented percentages).
   - Soft skills cards: Problem Solving, Adaptability, Team Collaboration, Editing Skills, Effective Communication.
6. **Featured Projects & Deep-Dive Modals**:
   - **Chocolate Company Sales Dashboard (Power BI)**: Includes interactive simulation with regional slicers (`North America`, `Europe`, `Asia-Pacific`, `LATAM`) and dynamic KPI calculations.
   - **E-Commerce Product Gallery (HTML & CSS)**: Interactive product cards with Flexbox, hover elevations, ratings, and functional Add-to-Cart shopping bag counter.
7. **Certifications Showcase**:
   - All 6 verified certifications with year filtering (`2026`, `2025`) and search filter.
8. **Contact & Resume System**:
   - Direct Email and Phone quick actions with copy-to-clipboard toast notifications.
   - Interactive message dispatch form with prefilled email composition.
   - Full ATS-friendly resume viewer modal with print/save PDF and direct file download options.
9. **Dark / Light Mode**:
   - Clean theme toggle with persistent state in `localStorage` and curated contrast.

## 🚀 Running the Project Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Development Server
```bash
npm install
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
